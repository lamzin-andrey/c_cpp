Что такое landcoder и landdecoder


Это программы для простого шифрования текста.

Примерно в 2013 я захотел придумать свой алгоритм для шифрования текста. Почти простой xor.

Первую версию на сайте cracklab взломали очень быстро. Тогда я добавил функцию, перемешивающую алфавит в зависимости от пароля, который ввел пользователь перед шифрованием.

Повторить взлом вроде бы не удалось. Возможно, я назначил недостаточно большое вознаграждение за результат.

Но судя потому, что специалисты переключились на методы социальной инженерии, пытаясь подкинуть мне на компьютер троян для windows во время переписки, сам по себе алгоритм оказался достаточно крепким..

Пришлось объяснить, что у меня а) Xubuntu, б) Пароль от зашифрованного текста нигде всё равно не записан. Ну а то, что исходный код шифровальщика лежит на сайте в виде javascript файла, они и так должны были знать из ТЗ.

Жаловались на то, что вот без отладчика плохо. Пришлось рассказать про консоль отладки в Хроме.

Получил отзыв "не думал, что отладка web приложений такое муторное дело".

На том дело и закончилось.

Потом пришла эпоха нейросетей, доступных каждому. Я пытался расшифровать зашифрованный текст с помощью Deep Seek, показав ему шифровку и исходный код алгоритма.

Не удалось, во всяком случае пока. Поэтому я попросил DeepSeek переписать код на Lua и использую его, когда хочу что-то зашифровать в kolibri.

Я понимаю, что это не Cha-Cha, но мне пока хватает.

Как пользоваться в kolibrios


1 Для корректной работы должен быть активирован App+.

Его ярлык есть на рабочем столе Kolibri. Если неясно, где взять папку kolibrios - вам надо распаковать iso образ kolibri, папка там.


2 Прописываем файловые ассоциации для любых не занятых расширений, например *.enс и *.dec.

Для этого в файловом менеджере Eolite нажимаем на панельке слева Настройки и кнопку "Редактировать ассоциации файлов".

В открывшемся редакторе пишем в конец:

enc=/sd0/1/путь/к/файлу/landcoder.kex

dec=/sd0/1/путь/к/файлу/landdecoder.kex


3 Текстовому файлу, который хотим зашифровать даём расширение enc и открываем его в Eolite. Должно открыться окошко кодера.

Вводим пароль, жмём на ОК.

В окошке должна появиться надпись "Готово, завершусь через 3 секунды". А рядом с вашим .enc файлом должен появиться .dec файл.


4 Для расшифровки открываем .dec файл, в Eolite. Должно открыться окошко декодера.

Вводим пароль, расшифрованый текст сохраняется в .enc файл.

Для желающих повозиться с кодом и самому собрать.


1 Для корректной работы компилятора tcc должен быть активирован App+. Компилятор в /kolibrios/develop/tcc/tcc

2. Скрипт компиляции COMPILE.SH по умолчанию заточен на компиляцию landdecoder.kex. Нуждается в правке путей, указать /kolibrios/develop/tcc/tcc я не догадался, а править сейчас лень.

3. Для компиляции landcoder.kex надо переименовать файл appcontroller.c во что угодно, а файл appcontroller_enc.c в appcontroller.c

Также надо в COMPILE.SH заменить landdecoder.kex на landencoder.kex.

4. В случае ошибок сборки (что-то исправили и не собирается kex) надо закомментровать строчку `pkill tcc` - тогда окошко компилятора не закроется, вы сможете прочитать ошибки и исправить.

5. Программа использзует мой фреймвёрк lldProject для удобного создания приложений для kolibri os на языке C - удобного в том виде, в котором я это понимаю.

Документация по уже реализованым функциям фреймвёрка в ../../landlib/desktop/api/doc.

Дока версталась так, чтобы хорошо выглядеть в webview kolibrios. Читать лучше в нём.

Файл generic/main.c трогать не надо, в будущем он будет гненерироваться. Для всех программок созданных с помощью lldProject он практически одинаковый, меняется только флаг окна, позволяющий разворачивать его на весь экран.

Вся логика C приложения в appcontroller.c

Вам доступны порты некоторых функций PHP (смотрите ../../landlib/dummyphpc/dphpc.h)

Вся логика кодирования / декодирования в LUA скриптах которые лежат в папке lua.
