Для удобства восприятия и совместимостью с документацией QtWebView API, (страницу по ссылке лучше открыть в современном браузере), имена функций имеют формат ИМЯ-КЛАССА_МЕТОД, хотя на самом деле в C конечно никаких классов нет.
Так, если вы видите функцию App_dir она максимально похожа на функцию App.dir из API по ссылке выше.

Это API создано быть максимально совместимым с API по ссылке выше.
Поэтому многие функции часто возвращают указатели на char.
Важно помнить золотые правила:

1 Если функция этого API возвращает char*, значит вы обязаны сделать free(result), если обратное не указано в документации функции

2 Если ваше приложение собирается работать в несколько потоков, Appinit() должен вызываться только один раз, в первом потоке. Это снимает все проблемы с потокобезопасностью.

Для всех, кого такой подход пугает (коллеги боятся забыть сделать free(), если не будут передавать символьный result по ссылке) существуют дубликаты функций с префиксом s (сокращение от safe).
