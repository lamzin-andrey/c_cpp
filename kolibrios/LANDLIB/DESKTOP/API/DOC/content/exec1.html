Взаимодействие с окружением - Env.exec1.

Env.exec1 Запускает другую программу. Пока не удаётся реализовать полный аналог QtWebView API Env.exec этот ментод можно использовать для замены (отсюда и суффикс 1). Возвращает идентификатор запускаемого процесса.
int Envexec1(char* executeFile, char* arguments);
Аргументы
char* executeFile Путь к исполняемому файлу.
char* arguments Аргументы, передаваемые исполняемому файлу.
Env.kill Завершает другую программу.
void Envkill(unsigned int processId);
Аргументы
unsigned int processId Системный идентификатр процесса. Его возвращает функция Envexec1 и будет возвращать Envexec во втором элементе массива.
