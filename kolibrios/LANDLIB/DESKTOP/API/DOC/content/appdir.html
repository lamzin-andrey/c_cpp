Взаимодействие с окружением - App_dir.

App_dir Возвращает путь к каталогу, в котором находится исполняемый файл приложения.
Важно! В данном случае не надо никогда вызывать free(_app_dir), так как память под результат App_dir() выделяется один раз, при запуске приложения (вызов Appinit() в main.c). ;
char* App_dir();
Appdir Дубликат App_dir(). Возвращает путь к каталогу, в котором находится исполняемый файл приложения.
Важно! В данном случае не надо никогда вызывать free(_app_dir), так как память под результат App_dir() выделяется один раз, при запуске приложения (вызов Appinit() в main.c). ;
char* Appdir();
sApp_dir Сверх-безопасная версия. Явно передаём результат и размер буфера в функцию, что должно подсказать C программисту необходимость очистить буфер в клиентском коде. Возвращает 1 если удалось поместить путь к каталогу приложения в size символов и 0 в противном случае.
int sApp_dir(char* result, UINT size);
