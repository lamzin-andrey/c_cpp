Взаимодействие с окружением - Env_open[X]Dialog.

Env_openFileDialog Запускает системный диалог открытия файлов.
char* Env_openFileDialog(char* caption, char* catalog, char* filter);
Аргументы
char* caption Должен устанавливать заголовок окна выбора файлов. В настоящее время не работает.
char* catalog Указывает, файлы какого каталога показать.
char* filter Определяет, файлы каких расширений надо показывать в диалоге выбора файлов. Например "*.txt *.c *.sh".
Расширения разделяются одним пробелом. Формат фильтра выбран таким же, как в соответствующей функции QtWebView API (а в QtWebView API он выбран таким же, как в соответствующем методе Qt5).
reurn char* Возвращает путь к выбранному файлу или пустую строку если файл не выбран
Env.openDirectoryDialog Запускает системный диалог выбора каталога.
char* EnvopenDirectoryDialog(char* caption, char* catalog);
Аргументы
char* caption Должен устанвливать заголовок окна выбора файлов. В настоящее время не работает.
char* catalog Указывает, файлы какого каталога показать.
reurn char* Возвращает путь к выбранному каталогу или пустую строку если каталог не выбран

Про безопасновть этих методов.

Все три вышеперечисленных метода всегда возвращают один и тот же адрес. Существует глобальная системная структура open_dialog*lld_dlg_open; Структура один раз инициализируется вызовом системной функции kolibri_new_open_dialog(). Происходит эта инициализация при первом вызове любого из трёх методов.

Все последующие вызовы изменяют поля mode и filter_area глобальной структуры. И возвращают её поле lld_dlg_open->openfile_path (либо пустую строку, если lld_dlg_open->status != SUCCESS).

Тем не менее, для всех, кого это не убедило, существуют копии методов с префиксом s (от safe), которые возвращают void.
