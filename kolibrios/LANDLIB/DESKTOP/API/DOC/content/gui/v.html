Взаимодействие с элементами GUI - char* v().

v() Возвращает значение инпута, либо текст внутри метки. Может использоваться для изменения этого текста, тогда надо передать вторым аргументом не NULL.
char* v(char* id, char* value);
Аргументы.
char* id Идентификатор элемента. Инпуту (или текстовому элементу) присваивается id при создании инпута с помощью функции Element createElementIfNotExists(char* type, char* id); или её сокращенного псевдонима Element cine(char* type, char* id).
Также id это первый аргумент всех lld* функций, создающих GUI элементы, таких как lldButton, lldText, lldIText и других.
В функции V() этот id используется для доступа к элементу.
char* value Переданное значение устанавливается найденному по id инпуту.

Первый шаг к пониманию этой функции для веб-программиста:
Функция V() вдохновлена функцией jQuery $.val(id, value); Для инпутов она работает аналогично.
Важно: Для инпутов типа icheckbox вернёт строку "On" или "Off". Но для установки чекбокса надо передавать не NULL, а для снятия чекбокса NULL.

Второй шаг к пониманию для веб-программиста:

Мне всегда не хватало в jQuery.val() возможности использовать эту функцию для установки innerText (и даже innerHTML). Поэтому v("idTextElement", "Hello world") умеет устанавливать текст внутри элементов типа "text";
Element textElement = createElementIfNotExists("text", "myTextBlock", "Hello World");
//Element textElement = cine("text", "myTextBlock", "Hello World");

v("myTextBlock", "How are you"); // Установит новый текст внутри элемента

Третий шаг к пониманию для веб-программиста:

Если установка текста внутри элемента типа "text" кажется вам логичной, попробуйте развить эту мысль и понять, что нет ничего плохого в установке пути к изображению этой же функцией для элемента типа "img".
Поэтому v("idImageElement", "/sd0/1/LIVES/KOLIBRI/HDATA/IMG/0.png") умеет устанавливать новое изображение на элементах типа "img";
Element imageElement = createElementIfNotExists("img", "image1", "/sd0/1/LIVES/KOLIBRI/HDATA/IMG/green.png");
//Element imageElement = cine("img", "image1", "/sd0/1/LIVES/KOLIBRI/HDATA/IMG/green.png");

v("image1", "/sd0/1/LIVES/KOLIBRI/HDATA/IMG/0.png"); // Выведет новое изображение внутри элемента (если файл существует)
Возвращаемое значение.
char* value Вернёт текущее значение инпута, если второй аргумент передан как NULL.
Для элементов типа "text" соответственно вернет текущее значение текста внутри элемента.
Для элементов типа "img" соответственно вернет текущий путь к изображению внутри элемента.

Про безопасность в этой функции

Внутри V() есть фрагментs кода, похожие на:

if (NULL != el.img->src) {
   free(el.img->src);
}
То есть, если связанный с отображаемым элементом текст не NULL, он очищается перед тем, как установить ему новое значение. Это гарантирует своевременную очистку памяти.
Важно: для текстовых инпутов такой очистки не происходит (пока не удаётся реализовать, не вызвав падение).
