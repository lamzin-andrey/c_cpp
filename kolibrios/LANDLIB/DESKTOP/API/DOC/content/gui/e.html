Взаимодействие с элементами GUI - Element e().

e() Возвращает структуру Element
Element e(char* id);
Аргументы.
char* id Идентификатор элемента. Инпуту присваивается id при создании инпута с помощью функции Element createElementIfNotExists(char* type, char* id); или её сокращенного псевдонима Element cine(char* type, char* id). Также id это первый аргумент всех lld* функций, создающих GUI элементы, таких как lldButton, lldText, lldIText и других.
Возвращаемое значение.
Element element Структура Element определена в Landlib/desktop/sys/lldvars.h
Это API задумано так, что при работе с функцией e(id) вас должно интересовать только поле Element.type. Если оно равно строке "undefined", значит элемент не найден. Другие значения поля type определяют, какие именно свойства вы можете изменять с помощью функций v(), attr() и stl().
