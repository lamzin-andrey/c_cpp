Взаимодействие с элементами GUI - char* stl().

stl() Возвращает положение инпута либо его цвет. Может использоваться для изменения этих свойств, тогда надо передать третьим аргументом не NULL.
char* stl(char* id, char* propertyName, char* value);
Аргументы.
char* id Идентификатор элемента. Инпуту (или текстовому элементу) присваивается id при создании инпута с помощью функции Element createElementIfNotExists(char* type, char* id); или её сокращенного псевдонима Element cine(char* type, char* id).
Также id это первый аргумент всех lld* функций, создающих GUI элементы, таких как lldButton, lldText, lldIText и других.
В функции stl() этот id используется для доступа к элементу.
char* propertyName Переданное в третьем аргументе значение устанавливается свойству найденного по id инпута.

Список существующих свойств см. в таблице ниже.
char* value Переданное значение устанавливается свойству найденного по id инпута, которое называется, как указано во втором аргументе.
Возвращаемое значение.
char* value Вернёт текущее значение свойства инпута, если третий аргумент передан как NULL.

Про безопасность в этой функции TODO

Внутри V() есть фрагментs кода, похожие на:

if (NULL != el.img->src) {
   free(el.img->src);
}
То есть, если связанный с отображаемым элементом текст не NULL, он очищается перед тем, как установить ему новое значение. Это гарантирует своевременную очистку памяти.
Важно: для текстовых инпутов такой очистки не происходит (пока не удаётся реализовать, не вызвав падение).
